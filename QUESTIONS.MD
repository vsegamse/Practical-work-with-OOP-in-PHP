# Контрольные вопросы

**1. Чем класс отличается от объекта?**
Класс — шаблон (чертёж), описывающий свойства и методы. Объект — конкретный экземпляр, созданный по этому шаблону через `new`. По одному классу можно создать много объектов, у каждого свои данные.

**2. Для чего нужен конструктор и когда он вызывается?**
`__construct()` задаёт начальное состояние объекта (присваивает свойства, проверяет входные данные). Вызывается автоматически один раз в момент создания объекта оператором `new`.

**3. Что означает `$this` и почему он недоступен в статических методах?**
`$this` — ссылка на текущий объект внутри его методов. Статический метод принадлежит классу и вызывается без создания объекта (`Math::sum()`), поэтому «текущего объекта» нет и `$this` недоступен.

**4. Чем отличается `$obj2 = $obj1` от `$obj2 = clone $obj1`?**
Присваивание копирует только ссылку на объект: `$obj1` и `$obj2` указывают на один и тот же объект, изменение через одну переменную видно в другой. `clone` создаёт новый независимый объект с копией значений свойств (копия поверхностная: вложенные объекты остаются общими, если не определить `__clone`).

**5. Чем статическое свойство отличается от обычного? Как к нему обратиться?**
Обычное свойство хранится у каждого объекта отдельно. Статическое принадлежит классу и общее для всех объектов. Обращение: `ClassName::$prop` снаружи, `self::$prop` (или `static::$prop`) внутри класса.

**6. Что такое readonly-свойство и когда его можно присвоить?**
Свойство (PHP 8.1+), значение которого можно записать только один раз и только из области видимости класса, обычно в конструкторе. Повторная запись вызывает `Error: Cannot modify readonly property`. Свойство должно быть типизированным.

**7. Что такое продвижение свойств в конструкторе?**
Возможность PHP 8.0: модификатор доступа у параметра конструктора (`__construct(private string $name)`) одновременно объявляет свойство и присваивает ему значение, без отдельного объявления и `$this->name = $name`.

**8. Как реализовать цепочку вызовов методов?**
Каждый метод в конце делает `return $this;` и объявляет тип возврата `static` (или `self`). Тогда результат вызова — тот же объект: `$calc->add(5)->multiply(3)->add(1)`.

**9. Назовите три магических метода и случаи, когда PHP их вызывает.**
- `__construct` — при создании объекта через `new`;
- `__toString` — когда объект используется как строка (`echo $obj`);
- `__call` — при вызове несуществующего (или недоступного) метода; `__set` — при записи в несуществующее или недоступное свойство; `__destruct` — при уничтожении объекта.

**10. Чем `protected` отличается от `private` при наследовании?**
`protected` доступен внутри класса и в классах-наследниках, `private` — только внутри самого класса, наследники его не видят (обращение из наследника к private-свойству родителя даёт «Undefined property»). Снаружи недоступны оба.

**11. Что делает ключевое слово `final`?**
Для метода запрещает переопределение в наследниках, для класса — запрещает наследование от него. Нарушение приводит к фатальной ошибке при компиляции.

**12. Как работает `spl_autoload_register`?**
Регистрирует функцию-загрузчик. Когда PHP встречает неизвестный класс (`new`, `extends`, статический вызов и т. д.), он вызывает зарегистрированные загрузчики по очереди, передавая полное имя класса. Загрузчик находит файл и подключает его через `require`; если класс появился, PHP продолжает работу, иначе — `Class "..." not found`.

**13. Как стандарт PSR-4 связывает пространство имён и путь к файлу?**
Префикс пространства имён сопоставляется базовой папке, а остаток имени класса превращается в путь: `\` заменяется на `/`, добавляется `.php`. Например, при `App\` → `src/` класс `App\Models\User` лежит в `src/Models/User.php`.

**14. Когда нужно выполнять `composer dump-autoload`?**
После изменения секции `autoload` в `composer.json` (новый префикс, новая папка) и при использовании classmap, когда добавлены новые классы. Для обычных классов PSR-4 в уже зарегистрированной папке (новый файл `src/Models/Order.php`) повторный запуск не нужен.
